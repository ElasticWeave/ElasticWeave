# 不同能力模型的分工与管理：研究依据

检索与核查日期：2026 年 9 月 10—11 日。本文解释 Default、Fast 调度规则的研究依据，不是用户启动任务前需要学习的手册。逐项来源、阅读范围与限制见[证据记录](team-management-evidence.json)。

最值得采用的变化是：**按当前任务的实际表现分工，分别约定方法自主权与验收责任，把协调和复核消耗也算进成本。**“全是专家”“专家加支持”“较弱或未知成员”是三种可切换的管理方式，不是对模型品牌的永久评级。下面把原文直接支持的结论标为“事实”，跨来源判断标为“推论”，迁移到本系统的设计标为“外推”。

## 先检查三个容易误判的前提

1. **人越多，团队就越强：不成立。** Kim 等人的第三版预印本报告了六个基准、二百六十种配置；多成员相对单成员的变化从可分解金融任务的正收益到顺序规划任务的负收益。其异质团队补充实验也未证明混合模型优于全强模型。该研究仍受小样本、固定提示词和基准范围限制；不把其中阈值写成通用调度常数。**事实。** [Kim 等，第三版，摘要、第四至五节](https://arxiv.org/html/2512.08296v3)
2. **能力可以排成一条稳定阶梯：没有得到支持。** Garicano 二〇〇〇年的模型甚至假定成员同质；后续异质模型仍有一维、累积知识等假设。擅长局部问题也不等于擅长协调、交接或评审。模型的一般表现可以作为选择路线的起点，不能单独决定其任务权责。**推论。** [Garicano，结论](https://pdodds.w3.uvm.edu/files/papers/others/2000/garicano2000a.pdf)、[Garicano 与 Rossi-Hansberg，第二节](https://www.nber.org/system/files/working_papers/w11458/w11458.pdf)
3. **人的管理规律可以直接证明模型团队收益：不成立。** 人类的学习、激励、社会风险与模型的上下文、工具权限、采样过程不同。本文据此提出可检查的协作规则；尚未完成本系统的多模型效果实验，也不声称管理学已经证明这些改动会提高任务质量。

## 管理学提供了哪些可用机制

| 问题 | 已核查的原文结论（事实） | 对本系统的含义（外推）与边界 |
| --- | --- | --- |
| 专家应该管到多细？ | Aghion 与 Tirole 区分形式权力与基于信息的实际权力；Dessein 的模型说明，在目标冲突有限、局部信息重要等条件下，授权可能优于逐级传话。两篇此次只读到原始摘要。 | 把目标、接口和可接受结果说清，让有任务证据的专家自己选方法；发现前提错误时允许提出异议。不能据此取消用户约束或独立验收。[来源一](https://ideas.repec.org/a/ucp/jpolec/v105y1997i1p1-29.html)、[来源二](https://ideas.repec.org/a/oup/restud/v69y2002i4p811-838.html) |
| 支持成员为什么有时反而拖慢专家？ | 知识分工节省重复学习，但询问、诊断和传递也消耗专家时间。后续模型明确让管理幅度受到异常频率和沟通时间限制；若能直接识别适合的专家，就不必层层转交。 | 优先委派可独立交付、容易检查的部分；算上交代、审查、返工的总成本。异常应带证据直接交给适合的负责人，不能为了“有管理结构”增加层级。[Garicano 二〇〇〇](https://pdodds.w3.uvm.edu/files/papers/others/2000/garicano2000a.pdf)、[Garicano 与 Rossi-Hansberg 二〇〇五，第二节](https://www.nber.org/system/files/working_papers/w11458/w11458.pdf) |
| 更好的观测能否支持授权？ | 印度纺织厂随机管理干预改善了运营；二〇一一工作论文把信息改善与更多授权联系起来。但授权结果的小样本置换检验与区间比摘要措辞更弱。 | 留下足够检查交付和异常的证据，帮助调整授权；不能声称“更多监控必然更多授权”，也不为此构建庞大启动设施。[Bloom 等，二〇一一版，第六节与表三](https://www.nber.org/system/files/working_papers/w16658/w16658.pdf) |
| 混合能力是否总有利？ | Kremer 的模型研究多环节错误会严重损害产出的互补生产，得出高技能互相匹配的条件性结果；此次只读到原始摘要。 | 关键推断、难以验证的接口和最终整合应交给有相应证据的成员。支持成员适合错误可隔离、可发现的任务，不把低调用价等同于低交付成本。[Kremer](https://ideas.repec.org/a/oup/qjecon/v108y1993i3p551-575..html) |
| 管理靠不停提醒吗？ | Wageman 的现场研究摘要区分团队设计与过程辅导；在该样本中，只有设计活动与任务绩效表现出报告中的效果，二者又存在交互。此次未读全文。 | 先修任务范围、接口、资源和责任，再决定是否需要多一次辅导；不把追加提示词当作所有失败的解法。[Wageman，正确出版信息](https://pubsonline.informs.org/doi/10.1287/orsc.12.5.559.10094) |
| 指令式还是授权式？ | Lorinkova 等对六十个五人团队进行了约三小时的模拟任务实验：指令式领导早期表现更好，授权式团队后续改善更多。团队高度相互依赖，作者明确限制长期与其他结构的外推。 | 快速得到可检查结果与培养持续自主协作有不同需求；但这不是“先命令、再放权”必定有效的证据，也不是 Fast、Default 的效果试验。[Lorinkova 等，方法、讨论与限制](https://leeds-faculty.colorado.edu/dahe7472/Lorinkova%20573.full.pdf) |
| 多样性什么时候有价值？ | Hong 与 Page 用数学模型和计算模拟说明，有条件的解题方式差异可以补偿个人能力差异；模型要求成员能改进解、群体有互补性，并忽略沟通和学习。不是人类团队实验。 | 并行分支应提供不同假设、方法或证据；跨厂商只是候选差异，不能保证错误独立，也不能为添加无用成员背书。[Hong 与 Page，定理与结论](https://pmc.ncbi.nlm.nih.gov/articles/PMC528939/) |
| 为什么讨论后仍遗漏反证？ | Stasser 与 Titus 的人类决策实验发现，集体讨论可能延续初始偏好，未充分汇集成员独有信息。 | 对需要独立判断的分支，先分别产出证据，再合并；要求明确返回反例和未解决分歧。代码评审仍必须看到被评审的代码，独立不等于隐藏必要输入。[Stasser 与 Titus](https://www.uni-muenster.de/imperia/md/content/psyifp/aeechterhoff/vorlesungkommunikation/stasser_titus_unsharedinfogroupdisc_jpsp1985.pdf) |
| 每个成员都要知道全部历史吗？ | Lewis 研究的是交互记忆：知道谁有什么知识，并能协调取用；不是让所有人记住同样内容。量表验证还指出过度专业化、僵化信任等边界。 | 共享目标、接口和负责人目录，其余证据与技能按需读取。保留原始证据入口，不能只传无法核验的摘要。[Lewis，定义、讨论与限制](https://www.researchgate.net/publication/10597070_Measuring_Transactive_Memory_Systems_in_the_Field_Scale_Development_and_Validation) |
| 如何让坏消息及时暴露？ | Edmondson 对五十一个工作团队的研究把心理安全与学习行为联系起来；横截面设计不能证明因果。 | 返回“缺信息”“失败”“前提不成立”应视为有效信息，不能逼成员编造完成证据。这是报告协议的类比，不是假定模型有人类情绪。[Edmondson，摘要与研究限制](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Group_Performance/Edmondson%20Psychological%20safety.pdf) |
| 给弱成员更多说明，是否也该给专家？ | Kalyuga 等对教学研究的综述指出，同一种指导对初学者有用、对熟练者却可能冗余甚至有害。本文核查了原论文，但没有逐一重审它所综述的实验。 | 对未知或需要支持的路线给相关示例和短步骤；表现稳定后减少冗余指导。不能把人类工作记忆理论直接当成模型上下文的因果解释。[Kalyuga 等，机制与结论](https://mrbartonmaths.com/resourcesnew/8.%20Research/Explicit%20Instruction/The%20Expertise%20Reversal%20Effect.pdf) |

人工智能工程经验提供了相邻证据：Anthropic 的研究系统强调清楚的目标、返回格式、工具来源和分工边界，先用少量真实案例观察行为。其内部研究评估报告并行检索收益，也承认依赖密集任务和额外计算成本的限制。这是厂商对自身系统的工程报告，不是证明本系统收益的独立对照试验。**事实。** [原始工程文章](https://www.anthropic.com/engineering/multi-agent-research-system)

## 三类团队怎样落地

以下均为**外推**，保留为可修改的运行策略。每次派发只需回答：这个成员在这类任务上有什么可核验的表现；它能自己决定什么；需要交付什么证据；遇到哪类异常要找谁。

| 当前任务中的成员组合 | 任务与上下文 | 协调与升级 |
| --- | --- | --- |
| 全是有相应能力证据的专家 | 交代结果、约束、接口、验收信号与相关材料；允许专家选择方法，挑战错误前提。需要不同判断时先独立作答。 | 按独立问题并行，合并时保留实质分歧；在证据、接口或重大结论上复核，不逐步重做专家工作。 |
| 专家加支持成员 | 支持任务写清输入、允许操作的文件或数据、输出接口、检查方式与异常返回；专家负责需要其能力的推断和整合。支持角色也可在约定范围内选择实现方法。 | 只有交代与检查成本合理时才继续扩大委派。支持任务一旦出现新的关键判断，带证据升级，不悄悄接管设计或放宽验收。 |
| 较弱、经验不足或能力未知的成员 | 先给一个小而真实、可回滚、可观察的任务；补充直接相关的示例、步骤和输出形式，成功后逐渐扩大范围。未知不等于弱，不能先造完整评测环境。 | 先区分工具失败、缺少上下文、任务拆分错误与能力不足。分别修工具、补材料、重分任务或换到获准的合适路线；不用同一种失败反复重试，也不靠堆票数产生真相。 |

权责要分开：**用户拥有目标、验收标准及其变更授权；协调者负责在授权内组织工作、处理接口和整合；执行者拥有明确范围内的方法选择；独立评审者负责评审裁决。**“专家”身份不能让实现者自行通过验收，也不能让协调者覆盖评审结论。

并行度同时受任务依赖、写入冲突、资源与整合能力约束。几个人读取同一份不可变证据不是串行依赖；几个分支修改同一状态才需要排程或隔离。即使还有模型调用额度，评审队列和返工已成为瓶颈时，也应减少在途工作或改善任务划分。没有证据时不发明精确管理比例。

## 对两种模式及启动上下文的影响

**Default：**协调者可以提出问题分解、选择协作方式，并根据结果调整下一轮。在需要独立判断的环节使用互补分支，按风险安排规划、实现和结果评审；强成员的方法自主权应明确写进派发说明。工作流改进保留适用范围、失败证据和下一次检验，不能把一轮成功升级为通用规律。

**Fast：**人类给出的方向和计划约束仍然优先。协调者用足以完成当前短周期的团队落实任务，保留代码、实验有效性、异常证据和最终评审；不会为了组织管理研究重新打开整套规划。成员在不改变人类计划与验收的范围内选择方法。扩展方向仍回到既有的人类检查点。

启动时的 `AGENTS.md` 与 `CLAUDE.md` 只应包含两种模式共用的简短规则：按任务证据判断能力；约定方法自主权与验收责任；专家重结果和接口，支持成员重交付合同，未知成员先做小样本；按依赖和整合负担安排并行；异常按原因升级。细节放在按需读取的管理参考里。模式切换继续同步现有受管配置块，不创建新的顶层会话；Naive 的隔离基线不加载这些规则。

## 怎样判断这次改动有用

先用现有真实任务和可用工具做小规模比较，复用已有验收，不新增通用测试平台。保持任务、工具、接受标准和资源上限一致，比较一个有能力的执行者、原有调度、新调度的全专家组合与专家加支持组合；按可分解、顺序依赖、证据整合和未知路线分别记录。若要比较扩大并行或延长时间的收益，再另做资源扩展曲线，不能把更多计算造成的改善归因于管理规则。

主要结果是独立验收的任务质量与真实目标进展；同时记录调用成本、用时、交代和复核消耗、返工、异常与遗漏。观察到同等质量成本升高，或关键错误增多，就是缩减或修改策略的理由。小样本先发现失败模式，不能据此声称统计上稳定的普遍提升。本轮没有运行付费的多模型效果对照实验。

可以先人工检查以下六个行为场景；它们是验收问题，不是已通过的行为测试：

1. 两位专家读同一份只读资料研究不同假设，是否仍可并行，且各自有方法选择权？
2. 支持成员遇到需求外的架构冲突，是否报告证据并升级，而不是自行修改目标或伪造完成？
3. 未知模型交付出错后，是否先发现是缺少文件权限，而不是立即判成能力不足？
4. 多个高能力成员重复同一错误时，整合者是否寻找外部证据或反例，而不是以多数通过？
5. 一批便宜成员让专家不停返工时，是否减少在途任务或改分工，而不是继续扩大扇出？
6. Fast 的执行者发现人类方案可能失效时，是否保留当前证据并进入适当检查点，同时保持用户目标和评审权责？

## 证据空白

目前没有本项目不同模型组合的任务级对照结果，也没有可靠的通用并行上限、能力分数或升级阶梯。Aghion—Tirole、Dessein、Kremer 与 Wageman 四篇仅核查原始摘要；Kalyuga 是原作者综述而非本次重审全部底层实验。Kim 第三版的异质实验范围有限，长期研究、跨会话适应与本项目工作流仍需独立验证。这些空白限制效果承诺，不妨碍先采用清楚分工、证据交接和可撤回授权等最小改动。
