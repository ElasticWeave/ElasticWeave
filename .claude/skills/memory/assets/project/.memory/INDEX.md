# .memory INDEX - on-demand recall surface

- [MAIN.md](MAIN.md) - capped project memory for the main session; not a cross-task reference.
- `inbox/new/` - untriaged upward propagation.
- `inbox/promoted/` and `inbox/rejected/` - auditable triage lifecycle.
- `skills/<skill>.md` - skill-attached project lessons.
- `agents/<agent>.md` - recurring agent lessons.
- `workflows/<flow>.md` - workflow lessons.
- `main/<slug>.md` - detail linked from MAIN.md.

Everything in this tree remains project-level. Cross-task promotion is a separate reviewed operation;
inbox or MAIN promotion alone never establishes transferability.
